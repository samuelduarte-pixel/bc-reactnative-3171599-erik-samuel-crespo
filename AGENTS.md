# Convenciones del proyecto

## Formato de commits para las semanas del bootcamp

Usar el formato:
```
feat: Semana X — Titulo de la semana
```

Ejemplos:
- `feat: Semana 7 — Persistencia Local`
- `feat: Semana 8 — Autenticación`
- `feat: Semana 9 — Animaciones Básicas`

Aplica de la semana 3 en adelante.
