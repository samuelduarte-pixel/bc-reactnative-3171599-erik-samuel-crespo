# Glosario — Semana 04

| Término | Definición |
|---|---|
| **Store** | Objeto que contiene el estado global y las acciones para modificarlo |
| **Selector** | Función que extrae una parte específica del store para optimizar re-renders |
| **Persist** | Middleware que guarda el store en almacenamiento local (AsyncStorage) |
| **Hydration** | Proceso de cargar los datos persistidos al iniciar la app |
| **Partialize** | Configuración de persist para guardar solo ciertos campos del store |
| **Slice** | Patrón para dividir un store grande en secciones más pequeñas |
| **Middleware** | Función que envuelve la creación del store para agregar funcionalidades |
